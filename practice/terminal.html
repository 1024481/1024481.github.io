Introduction to the Terminal

What is the Terminal?

The terminal (also called the command line or shell) is a powerful tool for interacting with your computer using text commands.

Why Learn the Terminal?

  • Fast file management
  • Automate tasks
  • Remote server access
  • Many developer tools require it

How to Open the Terminal

  1. Windows: Press Windows + R, type cmd, and press Enter.
  2. macOS: Open Spotlight (Cmd + Space), type Terminal, and press Enter.
  3. Linux: Press Ctrl + Alt + T.

Common Terminal Commands

  • pwd — Print working directory
  • ls — List files and folders
  • cd — Change directory
  • mkdir — Make new directory
  • touch — Create empty file

Code Example

Here is how you can create a folder, move into it, and create a file:


mkdir my_folder
cd my_folder
touch hello.txt

Here’s what an HTML heading looks like in code: 

<h1>Hello, World!</h1>

Sample Session

Run the following command to see a list of files:

ls

Example output:

hello.txt

How to Exit

Type exit and press Enter to close the terminal.
